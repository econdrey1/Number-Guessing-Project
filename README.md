# Number Guessing Project


## About the Project

I created this Number Guessing Game as part of Day 12 of my 100 Days of Python course. The program challenges players to guess a randomly generated number between 1 and 100.

The main goal of this project was to practice using Python functions, loops, conditional statements, and variables while creating a game that gives players feedback based on their guesses.

## How the Game Works

1. The program randomly selects a number between 1 and 100.
2. The player chooses between easy and hard difficulty.
3. Easy mode gives the player 10 attempts, while hard mode gives them 5 attempts.
4. The player enters a number to guess.
5. The program tells the player whether their guess is too high or too low.
6. Each incorrect guess reduces the number of remaining attempts.
7. The game ends when the player guesses the correct number or runs out of attempts.

## Python Concepts I Used

- **Functions:** Checks guesses, sets the difficulty, and controls the game.
- **Random Module:** Generates a random number between 1 and 100.
- **While Loops:** Keeps the game running until the player wins or loses.
- **If/Elif/Else Statements:** Determines whether a guess is too high, too low, or correct.
- **Variables:** Stores the correct answer, player's guesses, and remaining attempts.
- **Constants:** Sets the number of attempts for each difficulty level.
- **Return Statements:** Sends the number of remaining attempts back to the game.
- **User Input:** Allows players to select their difficulty and enter guesses.

## How to Run the Program

1. Download or clone this repository.
2. Make sure Python is installed.
3. Open the project in PyCharm or another Python editor.
4. Run `main.py`.
5. Choose your difficulty level.
6. Start guessing numbers until you win or run out of attempts.

## What I Learned

While working on this project, I learned how to use functions to organize different parts of a program. I also got more practice using while loops and conditional statements to control how a game works.

One thing I learned was how to keep track of the number of attempts a player has and update that number after each incorrect guess. I also learned how to use constants to set different difficulty levels.

This project helped me improve my problem-solving skills and understand how different Python concepts work together to create an interactive game.
